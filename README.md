# Peruanito

Pipeline concurrente en Go para el procesamiento de textos legales del Diario Oficial El Peruano.

## Características
- Limpieza de texto (normalización, tildes, caracteres especiales)
- Tokenización
- Eliminación de stopwords
- Eliminación de duplicados
- Procesamiento secuencial y concurrente
- Modelado en Promela

## Objetivo
Evaluar el rendimiento (speedup) del procesamiento concurrente sobre grandes volúmenes de datos.

## Dataset
Fuente: Plataforma Nacional de Datos Abiertos - Dispositivos Legales (El Peruano)
